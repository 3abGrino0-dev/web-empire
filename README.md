# إمبراطورية الويب — Web Empire Zero v3

مشروع مستقل مبني من الصفر ليكون **مصنع أدوات SaaS متعدد اللغات والمزودات** على `webempire.site`.

## النواة الحالية

- Next.js 16 App Router وRTL/LTR حسب اللغة.
- Supabase Auth وRLS وVault.
- Smart Country Language Router.
- Visual Identity Engine من لوحة الإدارة.
- Database-first Tool Factory.
- **Visual Tool Builder Wizard** بدون JSON للاستخدام اليومي.
- Dynamic input schema وPlan Access Limits.
- Formula Engine آمن بدون `eval`.
- Text Transform Runtime.
- AI Text وAI Structured.
- HTTP API وWebhook عبر Trusted Runtime Connections.
- Sequential Workflow Runtime مع Step Runs.
- Universal AI Provider Engine.
- OpenAI Responses / Anthropic Messages / Gemini / OpenAI-compatible / Custom HTTP.
- Universal Skills بالإصدارات.
- Plans + Credits + Wallet + Ledger.
- Reserve / Settle / Release للنقاط.
- Stripe Checkout subscription adapter.
- Billing webhooks مع signature verification وidempotency.
- Subscription credit grants مرة واحدة لكل billing period.
- Admin محمي وسجلات تشغيل وفوترة.

## المسارات الإدارية الجديدة

- `/admin/tools/new` — Visual Tool Builder
- `/admin/connections` — Runtime Connections
- `/admin/workflows` — Workflow Builder
- `/admin/billing` — Billing Provider + Plan Price Mapping
